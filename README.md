# Velora Maps website

Static pages for `https://loopenders.github.io/veloramaps/`:

- `index.html` — product overview
- `support.html` — support and FAQs
- `pp.html` — privacy policy
- `terms.html` — terms and conditions

The `website` directory is the source of truth. Publish its contents at the root of the public `loopenders/veloramaps` GitHub repository with GitHub Pages set to deploy from the default branch root. Keep the app links and App Store metadata in sync when changing these pages.
